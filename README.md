# Poseidon's Spear Minecraft Plugin

Poseidon's Spear is a Paper Minecraft plugin that adds a custom trident with lightning strikes on impact, lightning attacks when hitting entities with a left-click, and a temporary water cage effect when thrown at a player while sneaking.

## Install

1. Use Java 21 or newer.
2. Run `mvn package` in the project directory.
3. Copy the generated `target/plugin.jar` file into your Paper server's `plugins` folder.
4. Start or restart the server.
5. Make sure the server is running Paper 1.21.11 or a compatible 1.21 server version.

## Use

1. Join the server with operator permission or the `poseidonspear.get` permission.
2. Run `/poseidonspear` to receive Poseidon's Spear.
3. Throw the spear at an entity or block. The spear strikes lightning at the hit location.
4. Hold the sneak key while throwing the spear at a player to create a temporary water cage around the target.
5. Attack an entity with Poseidon's Spear in your main hand to strike lightning on every successful entity hit.
6. The water cage lasts for approximately five seconds. Only air blocks are changed, and the plugin restores cage blocks that are still water when the effect ends.
